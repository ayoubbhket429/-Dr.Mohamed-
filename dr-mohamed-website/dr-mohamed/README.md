# موقع دكتور محمد — استشاري أمراض القلب

موقع تعريفي كامل لعيادة دكتور محمد (مدينة نصر – السراج مول – القاهرة)، مبني بـ HTML و CSS و JavaScript فقط (بدون أي Framework)، وجاهز للنشر مباشرة على GitHub Pages.

---

## 1) هيكل المشروع

```
dr-mohamed/
├── index.html          الصفحة الرئيسية (تحتوي كل الأقسام)
├── privacy.html         سياسة الخصوصية
├── terms.html            الشروط والأحكام
├── css/
│   └── style.css        كل تنسيقات الموقع (الألوان، الخطوط، الاستجابة)
├── js/
│   └── main.js           القائمة، الأسئلة الشائعة، نموذج الحجز، واتساب، التتبع
├── assets/
│   ├── favicon.svg       أيقونة الموقع
│   └── og-cover.jpg     صورة المشاركة على السوشيال ميديا
└── README.md
```

---

## 2) كيفية تشغيل الموقع محليًا

لا يحتاج المشروع أي تثبيت. يكفي فتح ملف `index.html` مباشرة في المتصفح.

للحصول على أفضل تجربة (خصوصًا مع النماذج)، يُفضّل تشغيل خادم محلي بسيط:

```bash
# داخل مجلد المشروع
python3 -m http.server 8000
# ثم افتح المتصفح على:
http://localhost:8000
```

---

## 3) كيفية تعديل اسم الدكتور

ابحث عن "دكتور محمد" داخل `index.html` (يظهر في الـ Header، الـ Hero، الـ About، الـ Footer... إلخ) واستبدله بالاسم الجديد. لا تنسَ تحديثه أيضًا في:
- وسم `<title>` في أعلى الصفحة
- `meta description` و `Open Graph`
- ملف `privacy.html` و `terms.html`
- الكائن (`Schema.org JSON-LD`) في نهاية `<head>` — الحقل `"name"`

---

## 4) كيفية تعديل رقم الهاتف

رقم الهاتف الحالي `01555227040` موجود في أماكن متعددة بصيغتين:
- الصيغة المحلية للعرض: `01555227040`
- صيغة الاتصال الدولية: `tel:+201555227040`

ابحث عن `01555227040` و `+201555227040` داخل `index.html` واستبدلهما بالرقم الجديد (بنفس الصيغتين). حدّث أيضًا حقل `"telephone"` داخل الـ Schema Markup.

---

## 5) كيفية تعديل رقم واتساب

رقم واتساب يُبنى تلقائيًا من ملف `js/main.js`. افتح الملف وعدّل السطر التالي في الأعلى:

```js
var WHATSAPP_NUMBER = '201555227040'; // بالصيغة الدولية بدون + أو أصفار زائدة
var WHATSAPP_MESSAGE = 'مرحبًا دكتور محمد، أرغب في حجز موعد بالعيادة.';
```

كل أزرار واتساب في الموقع (Header، الحجز، Floating Button، الفوتر) تُبنى تلقائيًا من هذين المتغيرين.

---

## 6) كيفية تعديل الموقع الجغرافي

ابحث عن "مدينة نصر – السراج مول" داخل `index.html` وعدّله. زر "فتح الموقع على الخريطة" في قسم `#location` يفتح بحث Google Maps بالاسم النصي للموقع؛ لعرض خريطة مضمّنة حقيقية بإحداثيات دقيقة، استبدل الـ `div.location-map-placeholder` بكود `<iframe>` من Google Maps Embed بعد تحديد إحداثيات العيادة بدقة.

---

## 7) كيفية تعديل الخدمات / تخصصات القلب

كل خدمة داخل قسم `#specialties` عبارة عن بطاقة `<div class="specialty-card">` تحتوي على أيقونة SVG وعنوان ووصف. لإضافة خدمة جديدة، انسخ إحدى البطاقات الموجودة والصقها داخل `.specialty-grid`، ثم عدّل العنوان والوصف. نفس الأسلوب ينطبق على بطاقات قسم "لماذا تختار العيادة" (`#why`).

---

## 8) كيفية تغيير الصور

الموقع يعتمد حاليًا على رسومات SVG مرسومة داخل الكود (بدلاً من صور فوتوغرافية) لضمان سرعة التحميل وسهولة النشر بدون الحاجة لملفات صور خارجية. لإضافة صور حقيقية:
1. ضع ملفات الصور داخل مجلد `assets/`.
2. استبدل أي عنصر `<svg>...</svg>` بعنصر `<img src="assets/اسم-الصورة.jpg" alt="وصف الصورة">`.
3. لصورة المشاركة على السوشيال ميديا (Open Graph)، استبدل `assets/og-cover.jpg` بصورة مقاسها 1200×630 بكسل تقريبًا.

## 9) كيفية تغيير الألوان

كل ألوان الموقع معرّفة في مكان واحد أعلى ملف `css/style.css` داخل `:root`:

```css
:root{
  --color-primary: #0B3D4C;   /* اللون الأساسي (Header, Footer, العناوين) */
  --color-accent: #C14953;    /* لون الأزرار الرئيسية وخط النبض */
  --color-bg: #F7F9FA;        /* خلفية الصفحة */
  ...
}
```

عدّل قيم الألوان هنا فقط، وستنعكس على كل عناصر الموقع تلقائيًا.

## 10) كيفية تعديل نصوص الموقع

كل النصوص مكتوبة مباشرة داخل `index.html` بالعربية. افتح الملف بأي محرر نصوص وابحث عن الجملة المطلوب تعديلها (مثال: استخدم Ctrl+F في VS Code) ثم عدّلها مباشرة. الأقسام مقسّمة بتعليقات واضحة مثل:

```html
<!-- ============================================================ HERO ============================================================ -->
```

## 11) مكان إضافة Google Tag Manager

داخل `index.html`، ابحث عن التعليق:

```html
<!-- GOOGLE TAG MANAGER — ضع كود GTM هنا -->
```

هذا التعليق موجود في أعلى `<head>`. الصق كود GTM الذي تحصل عليه من tagmanager.google.com مكان التعليق مباشرة.

---

## 12) مكان إضافة Meta Pixel و Google Analytics و TikTok/Snapchat Pixel

بنفس الطريقة، ستجد داخل `<head>` تعليقات مخصصة لكل أداة:

```html
<!-- GOOGLE ANALYTICS (GA4) — ... -->
<!-- META PIXEL — ... -->
<!-- TIKTOK PIXEL — ... -->
<!-- SNAPCHAT PIXEL — ... -->
```

الصق كود كل أداة مكان التعليق الخاص بها. الأحداث التالية جاهزة للتتبع تلقائيًا عبر خاصية `data-track` في `js/main.js` (داخل دالة `initTrackedClicks`):
- `phone-quickinfo`, `phone-booking`, `phone-contact`, `phone-contact-btn` — الضغط على الاتصال
- `whatsapp-booking`, `whatsapp-contact`, `whatsapp-floating` — الضغط على واتساب
- `location-click` — الضغط على "فتح الموقع على الخريطة"
- حدث إرسال نموذج الحجز موجود داخل `initBookingForm()` في نفس الملف

افتح `js/main.js` وابحث عن التعليقات التي تبدأ بـ `// gtag(...)` أو `// fbq(...)` لإضافة كود الأحداث الفعلي.

---

## 13) كيفية ربط نموذج الحجز بخدمة خارجية (Webhook / CRM / Google Sheets / Email)

نموذج الحجز حاليًا يعرض رسالة نجاح فقط دون إرسال البيانات لأي جهة. لربطه بخدمة خارجية:

1. افتح `js/main.js` وابحث عن دالة `initBookingForm`.
2. ستجد تعليقًا يشرح المكان المناسب لإضافة كود الإرسال، شبيه بهذا:

```js
fetch('https://YOUR-WEBHOOK-URL', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(data)
})
  .then(function (res) { return res.json(); })
  .then(function () { showSuccess(); })
  .catch(function (err) { console.error('Booking submit failed:', err); });
```

3. استبدل `YOUR-WEBHOOK-URL` برابط الخدمة التي تريد ربطها (مثل Zapier أو Make.com أو Google Apps Script لربطه بـ Google Sheets، أو API خاص بك).

---

## 14) كيفية رفع المشروع على GitHub Pages

1. أنشئ Repository جديد على GitHub (مثال: `dr-mohamed-website`).
2. ارفع كل ملفات المشروع (بنفس الهيكل الموجود، مع الحفاظ على مجلدات `css` و `js` و `assets`) إلى الـ Repository.
3. من إعدادات الـ Repository، اذهب إلى تبويب **Settings → Pages**.
4. تحت "Build and deployment"، اختر Source: **Deploy from a branch**.
5. اختر الفرع `main` (أو `master`) والمجلد `/ (root)`، ثم اضغط **Save**.
6. انتظر دقيقة أو دقيقتين، وسيظهر رابط الموقع بالشكل:
   `https://USERNAME.github.io/dr-mohamed-website/`
7. تأكد من أن جميع الروابط تعمل بعد النشر (الصفحة الرئيسية، سياسة الخصوصية، الشروط والأحكام)، لأن المشروع يستخدم مسارات نسبية (Relative Paths) متوافقة تمامًا مع GitHub Pages.

## ملاحظات مهمة قبل التشغيل الفعلي

- **الخريطة:** قسم الموقع الجغرافي يحتوي حاليًا على زر يفتح بحث Google Maps بالاسم فقط (بدون إحداثيات دقيقة)، لأن العنوان التفصيلي داخل السراج مول لم يتم توفيره. أضف Google Maps Embed بإحداثيات دقيقة عند توفرها.
- **المحتوى الطبي:** كل النصوص الطبية في الموقع عامة وتعريفية فقط، ولا تحتوي على أي شهادات أو أرقام أو نتائج علاجية غير مؤكدة، بناءً على المعلومات المتوفرة وقت إنشاء الموقع.
- **صورة المشاركة (OG Image):** تم إنشاء صورة مبدئية بسيطة بألوان الموقع؛ يمكن استبدالها بصورة احترافية للعيادة أو الدكتور لاحقًا.
- **الخطوط:** الموقع يستخدم خطي Cairo و Tajawal من Google Fonts، ويتطلب اتصالاً بالإنترنت لتحميلهما بشكل صحيح عند فتح الموقع.
